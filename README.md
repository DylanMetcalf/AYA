# ULTIMA Experience Operations Platform

Internal operating system for designing, costing and delivering bespoke journeys across ULTIMA, AYA and Schmidt Car Hire.

```bash
cp .env.example .env        # then edit values
npm install
npm run db:migrate && npm run db:seed
npm run dev
```

Docs: `docs/` (start with `IMPLEMENTATION_PLAN.md`). Contributor conventions: `CLAUDE.md`.
